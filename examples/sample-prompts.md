# Sample Prompts

**Full report**
```
Run the SEO competitor gap report for yourbrand.com vs competitor-a.com,
competitor-b.com, competitor-c.com, competitor-d.com, competitor-e.com, competitor-f.com.
Focus page: yourbrand.com/services/b2b-seo/. Topic: "B2B SEO agency". Market: US.
Brand terms: yourbrand|your brand.
```

**Let Claude find the competitors**
```
Run the competitor gap report for yourbrand.com on "B2B SEO agency" in the UK.
Find the 5 most relevant organic competitors in Semrush first.
```

**Low-cost test run**
```
Do a test run of the competitor gap report: yourbrand.com vs 3 competitors,
one keyword ("b2b seo agency"), US. Skip AI visibility. Tell me the API units used.
```

**Different market**
```
Run the competitor gap report for yourbrand.com vs the same competitors,
but for the UAE market (Semrush database: ae).
```

**Section only**
```
Using the competitor gap report workflow, just build the backlink gap:
domains linking to 2+ of these competitors but not to yourbrand.com.
```
